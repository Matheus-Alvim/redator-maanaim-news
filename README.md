# Redator Maanaim News 🎙️

Site simples para a equipe preparar pautas e levar instruções de roteiro para o ChatGPT.

## Usar
1. Abra o site.
2. Escreva o título e conte o que aconteceu.
3. Escolha o formato (matéria completa, OFF, passagem, cabeça ou nota coberta).
4. Clique em **Preparar meu roteiro**.
5. Clique em **Copiar e abrir ChatGPT**, cole e envie.

O redator escreve apenas os textos de fala. **Entrevistas são espontâneas e não são roteirizadas.**

## Publicar gratuitamente no GitHub Pages
Na página do repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save**.

Depois de publicado, o endereço esperado será:
https://matheus-alvim.github.io/redator-maanaim-news/

> O link só funcionará depois de o Pages estar habilitado e a implantação ser concluída.

## Estrutura
- `index.html`: página
- `style.css`: identidade visual inspirada na comunicação Maanaim News
- `script.js`: formulário e instruções do redator

## Privacidade e limites
- O site não utiliza API de IA, não possui login e não armazena pautas.
- Ao colar o texto no ChatGPT, aplicam-se as configurações e regras da conta da pessoa.
- O repositório público contém apenas código. Não inclua dados internos ou sensíveis nele.
- Revisão humana é necessária antes da gravação.
- Ferramenta independente de apoio editorial, sem alegação de endosso oficial.
